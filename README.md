# Curbside demo

Public, static frontend demo with fictional sample parking data.

Live demo: https://ashyamala.github.io/curbside-demo/

No backend, private data, or credentials are included. Search, filters, selection, and saved places work in the browser. This demo cannot determine parking legality or availability.

GitHub Pages serves main from the repository root. Updating index.html here republishes the demo; changes to the private app repository are not automatically copied here.
